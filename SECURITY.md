# Security

Report a vulnerability in gleon, its Flutter package or this site privately through
[GitHub's private vulnerability reporting](https://github.com/gleon-rs/gleon/security/advisories/new)
of the CLI repository. Please do not open a public issue for it.

This site is static HTML and CSS, without JavaScript, cookies or third-party requests.
`/.well-known/security.txt` names the same contact and expires on November 1, 2027: renew its
`Expires` line before then.
